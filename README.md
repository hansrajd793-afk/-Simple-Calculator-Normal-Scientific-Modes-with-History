🧮 Simple Calculator — Normal & Scientific Modes with History

A clean, intuitive, and lightweight Calculator Application built with two powerful modes:
Normal Mode for everyday arithmetic and Scientific Mode for advanced calculations.
The project also includes a History Feature that logs all previous calculations for easy review.

✨ Features
🔹 Dual Calculator Modes

Normal Mode:
Perform basic operations like addition, subtraction, multiplication, and division.

Scientific Mode:
Access advanced functions such as trigonometry, logarithms, exponentials, square roots, and more.

🔹 Calculation History

Automatically saves all past calculations.

Users can view, scroll, or clear their history at any time.

Helps track long sessions or complex workflows.

🔹 User-Friendly Interface

Clean and minimalistic design.

Easy to navigate between normal and scientific modes.

Clear display area for both input and results.

🔹 Lightweight & Efficient

Small codebase with well-structured functions.

Fast, responsive performance with no unnecessary dependencies.
🚀 How It Works

Select Normal or Scientific mode.

Input your values and operations.

View results instantly on the display.

All calculations are stored in the History Panel for reference.
